# Guitar-for-Dad

Simple materials and tracking for guitar lessons.

## Structure

- `lessons/`: Notes and tabs for each lesson.
- `practice-log/`: Short daily or weekly practice notes.
- `resources/`: Chords, scales, and reference material.

## Suggested Workflow

1. Add one markdown file per lesson in `lessons/`.
2. Record practice sessions in `practice-log/`.
3. Keep reference sheets in `resources/`.

## Naming Convention

- Lessons: `YYYY-MM-DD-topic.md`
- Practice log: `YYYY-MM.md`
